How to Run the System

WHAT YOU NEED
-------------
- Python 3.10 or higher (download from python.org)
- PyQt6 (install with command below)

SETUP STEPS
-----------
Step 1: Extract the zip file
    Extract the zip file. Open the pams folder inside it.
    You should see main.py inside the pams folder.

Step 2: Open a terminal inside the pams folder
    On Windows: go into the pams folder, click the address bar, type cmd, press Enter.

Step 3: Install PyQt6
    pip install PyQt6

Step 4: Run the app
    python main.py
    The login window will open. The database is created automatically on first run.

HOW TO RUN THE AUTOMATED TESTS
-------------------------------
    pip install pytest
    python -m pytest tests/test_pams.py -v
    All 52 tests should pass.

RESET THE DATABASE
------------------
Delete the database file and run the app again:
    del database\pams.db
    python main.py

TROUBLESHOOTING
---------------
- App doesnt start: make sure you are inside the pams folder where main.py is
- Module not found: run pip install PyQt6 again
- Database error: delete database\pams.db and run again
